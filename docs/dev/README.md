# Документация разработчика

Что где искать:

- [`architecture.md`](architecture.md) — концепция, из чего состоит система, как компоненты работают вместе, pull-модель, владение Reality-ключами, типы воркеров.
- [`api.md`](api.md) — все эндпоинты vpn-core, тела запросов/ответов.
- [`ci-cd.md`](ci-cd.md) — что реально настроено в CI/CD прямо сейчас, и что делается вручную.
- [`known-issues.md`](known-issues.md) — открытый техдолг, который стоит знать перед тем как трогать соответствующий код.

## Что не здесь

- **`personal/`** — операционные bootstrap/deploy-скрипты и `worker_manual.md` с конкретными командами для реального деплоя. Не версионируется (гитигнорится) — приватный рабочий инструментарий оператора, не публичная документация проекта.
- **`docs/spec.md`** — авто-сгенерированный дамп дерева файлов, не документация, не редактируется руками. Не версионируется, может отсутствовать.
- **`/CLAUDE.md`** (корень репозитория) — инструкции для Claude Code: та же концепция в сжатом виде плюс project-специфичные правила разработки (сборка, тесты, что нельзя делать). Не версионируется, локальный файл.
